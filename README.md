# 01 / SKILL VAULT

### Connecting people who have skills with people who need them.

SkillVault is a freelancing platform that allows users to showcase their skills, discover freelancers, communicate securely, and manage projects through one application.

### Features

✔ User Authentication

✔ Freelancer Profiles

✔ Skill Listings

✔ Project Posting

✔ Razorpay Integration

✔ PostgreSQL Database

✔ Responsive UI
